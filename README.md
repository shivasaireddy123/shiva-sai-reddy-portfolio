# Animated React Portfolio — Nathala Shiva Sai Reddy

A premium, responsive React/Vite portfolio generated strictly from the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes
- Portfolio content is centralized in `src/data/portfolio.js`.
- The resume did not expose actual URLs for LinkedIn, GitHub, Portfolio, or project links—only labels—so no links were fabricated.
- The contact form is client-side only and does not send email.
- The supplied resume is the source of truth; no profile image was invented or added.
